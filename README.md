# ai-poopifyer
This is a server which traps ai bots inside it's structures and feeds it... well, look at the name.

<img src="poop.jpg" alt="an ai crap bot in a crap pit" style="width:35%;height:35%;">

<br>
**Installation:** Just copy the welcome.js file to your webserver and "chmod +x welcome.js" it. Afterwards you can start it with ./welcome.js

The standard port is 8080 but you can edit the line inside the file: "const PORT = Number(process.env.PORT || 8080);".

I hope you enjoy it.
