<br> <br>
<b>Installation:</b> 
<br>
<br> Just copy the welcome.js file to your webserver and "chmod +x welcome.js" it. Afterwards you can start it with ./welcome.js

The standard port is 8080 but you can edit the line inside the file: "const PORT = Number(process.env.PORT || 8080);".
